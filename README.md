# HUSSAINE

HUSSAINE is an offline-friendly Android security-learning companion built with Kotlin and Jetpack Compose.

## Features
- Home dashboard
- Security and privacy learning cards
- Manual note preview
- Simulated terminal with harmless demo commands
- No Android permissions declared in the manifest

## Build
The GitHub Actions workflow builds a debug APK with JDK 17, Android SDK 35, and Gradle 8.9.

After a successful workflow run, download the `HUSSAINE-debug-apk` artifact from the Actions run.

## Scope
This project is for defensive learning and personal digital safety. It does not perform wireless scanning, password cracking, exploitation, or actions against other devices.
